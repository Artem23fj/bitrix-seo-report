# SEO-отчёт по товарам

## Назначение

Компонент `artem:seo.report` формирует отчёт по SEO-готовности товаров основного торгового каталога 1С-Битрикс.

## Возможности

- автоматическое определение основного инфоблока каталога;
- получение до 20 активных основных товаров;
- торговые предложения SKU отдельно не анализируются;
- проверка наличия описания и изображения;
- проверка заполненности характеристик;
- получение итоговых наследуемых META TITLE, META DESCRIPTION и META KEYWORDS через стандартный API Bitrix;
- расчёт `SEO_SCORE` от 0 до 100;
- отображение причин потери баллов;
- фильтрация по диапазону SEO;
- сортировка по SEO-оценке и названию товара.

## Формула SEO_SCORE

| Критерий | Баллы |
|---|---:|
| Описание | 20 |
| Фото | 15 |
| Характеристики | 15 |
| META TITLE существует | 15 |
| Длина META TITLE — 30–65 символов | 5 |
| META DESCRIPTION существует | 15 |
| Длина META DESCRIPTION — 70–170 символов | 5 |
| META KEYWORDS существует | 10 |

Максимальная оценка — **100 баллов**.

## Требования

- 1С-Битрикс: Управление сайтом;
- модуль `iblock`;
- модуль `catalog`;
- PHP 8.2 или новее.

## Установка и подключение

Компонент должен находиться в каталоге:

```text
/local/components/artem/seo.report/
```

Минимальный пример подключения:

```php
<?php
$APPLICATION->IncludeComponent(
    'artem:seo.report',
    '',
    []
);
```

## Структура компонента

- `.description.php` — описание компонента и его расположение в списке компонентов Bitrix.
- `component.php` — получение товаров, анализ данных, расчёт SEO-оценки, фильтрация и сортировка.
- `templates/.default/template.php` — форма фильтра и HTML-таблица отчёта.
- `templates/.default/style.css` — локальное оформление формы и таблицы.

## GET-параметры

- `seo_min` — минимальная SEO-оценка, от 0 до 100; по умолчанию `0`.
- `seo_max` — максимальная SEO-оценка, от 0 до 100; по умолчанию `100`.
- `sort` — порядок сортировки; по умолчанию `score_asc`.

Допустимые значения `sort`:

- `score_asc` — сначала товары с наиболее низкой SEO-оценкой;
- `score_desc` — сначала товары с наиболее высокой SEO-оценкой;
- `name_asc` — по названию товара.
